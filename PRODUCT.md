# Product

## Register

product

## Users
Developers and technical users who want to use Verboo Code as a desktop coding assistant without living in the CLI.

## Product Purpose
Verboo Code provides an installable desktop shell for the Verboo CLI experience: chat, model selection, skills, project context, permissions, profile usage, and local machine access in one focused app.

## Brand Personality
Quiet, direct, capable. The app should feel like a professional developer tool with Verboo identity, not a generic AI chat product.

## Anti-references
Avoid marketing-style AI chrome, oversized assistant branding, decorative panels, raw terminal escape output, noisy warning blocks, and full paths when a short project name is enough.

## Design Principles
- Keep the product chrome quiet so the workspace and conversation stay primary.
- Make risky or account-related states explicit, but never raw or alarming without explanation.
- Use Verboo color as an operational signal, not decoration.
- Prefer familiar desktop app affordances over custom novelty.
- Preserve CLI power while filtering terminal implementation details out of the UI.

## Accessibility & Inclusion
Use readable contrast, keyboard-reachable controls, reduced-motion-safe transitions, and text wrapping that handles long paths, model ids, and code-related strings without overflow.
