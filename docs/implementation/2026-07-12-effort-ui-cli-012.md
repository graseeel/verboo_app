## Goal

Tornar effort dinâmico funcional ponta-a-ponta: usuário seleciona nível de esforço por modelo via UI aprovada B, preferência persiste em `UserSettings.effortByModel` (fonte única), nível é passado como `--effort <level>` ao CLI 0.12.0+, e prova-se via Gate A (args Rust) e Gate B (CLI smoke). Gate C (Router/provider) é requisito externo que bloqueia release sem prova observável.

---

## Architecture

`Router raw.reasoning` → `extract_reasoning()` promove `ModelReasoning` → FE `App.tsx` computa `validOverride`/`displayEffort`/`requestEffort` → `AgentTurnRequest.effort` → Rust `turn_service` monta `--effort <level>` → CLI 0.12.0+ aceita via `getVerbooReasoningEffort`. Preferência flui: FE → `updateUserSettings({ effortByModel })` → Rust persiste em `settings.json`. Migração única de localStorage legado com segurança async.

### 6. FE — Migração localStorage segura (sem corrida)

- [ ] **6a. Estado inicial vazio, carregar backend primeiro**
  - State inicial: `{}` (vazio). Após `getUserSettings()` resolver, usar backend se populado.
  - Se backend vazio, aplicar fallback localStorage.
  ```typescript
  // Estado inicial: vazio — evitar corrida entre backend e localStorage
  const [effortByModel, setEffortByModel] = useState<Record<string, string>>({})
  const EFFORT_BY_MODEL_KEY = 'verboo:effort-by-model'

  // Após carregar userSettings do backend
  useEffect(() => {
    if (!userSettings) return
    const backendData = userSettings.effortByModel
    if (backendData && Object.keys(backendData).length > 0) {
      // Backend é fonte primária
      setEffortByModel(backendData)
      // Cleanup seguro: se localStorage existe, remover
      window.localStorage.removeItem(EFFORT_BY_MODEL_KEY)
      return
    }
    // Backend vazio: tentar fallback localStorage
    try {
      const raw = window.localStorage.getItem(EFFORT_BY_MODEL_KEY)
      if (!raw) return
      const parsed = JSON.parse(raw)
      if (typeof parsed !== 'object' || parsed === null) return
      // Validar entradas
      const valid: Record<string, string> = {}
      for (const [k, v] of Object.entries(parsed)) {
        if (typeof v === 'string' && v !== '') valid[k] = v
      }
      if (Object.keys(valid).length === 0) return
      // Aplicar local — ainda não persistiu no backend
      setEffortByModel(valid)
      // Migrar para backend: só remove localStorage se sucesso
      window.verboo.updateUserSettings({ effortByModel: valid })
        .then(() => window.localStorage.removeItem(EFFORT_BY_MODEL_KEY))
        .catch(() => { /* manter localStorage para retry */ })
    } catch { /* ignore parse errors */ }
  }, [userSettings])
  ```
